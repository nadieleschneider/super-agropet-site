# 🐾 Super Agropet - Site Institucional

Landing page moderna, responsiva e focada em conversão para o **Super Agropet**, desenvolvida para apresentar os serviços de banho e tosa, tratamentos estéticos e produtos especializados para pets.

## 🚀 Tecnologias Utilizadas
* **Estruturação:** HTML5
* **Estilização & Design:** Tailwind CSS
* **Interatividade:** JavaScript moderno

## ✨ Principais Funcionalidades
* **Apresentação da Marca:** Missão, valores e compromisso com o bem-estar animal.
* **Secção de Serviços:** Detalhes sobre banho e tosa, pacotes de hidratação e spa relaxante.
* **Agendamento Rápido:** Links diretos integrados com o WhatsApp para agendamentos ágeis.
* **Design Responsivo:** Adaptado perfeitamente para computadores, tablets e telemóveis.
